The office printer finally answers back. One line, 104 characters, in the machine's own weary, literal, faintly passive-aggressive voice:

> Beep. I have fed 38,412 sheets without complaint. You cleared one jam and now you act like you fixed me.

Built for the [make.fun "The Printer Finally Answers" bounty](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907): a single line of text (1–240 characters) that the office printer would say back to everyone staring at it — the paper jams, the cryptic error codes, the thumps when it stops working. Judged pairwise by the house judge on humour first, then the printer's voice, then how cleanly the comeback lands.

## Run it

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable is unset), after validating it is a single non-blank line of 1–240 characters.
